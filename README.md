# LaTeXReader: читалка PDF для Apple Watch

Простое приложение для Apple Watch (watchOS 10 и новее), которое показывает ваши PDF-документы прямо на часах. Документы прокручиваются пальцем, поэтому на часах удобно держать конспекты, шпаргалки, формулы и справочники, подготовленные в LaTeX.

Приложение **не компилирует LaTeX на часах**. Вы заранее собираете PDF на компьютере, кладёте файлы в проект, собираете приложение в Xcode и устанавливаете его на свои часы.

---

## Как это работает

1. Вы готовите документ в LaTeX (или любой PDF) с **узкой страницей под экран часов**, например шириной 60 мм.
2. Кладёте готовые PDF в папку `Documents` проекта.
3. Собираете и устанавливаете приложение на свои часы из Xcode.
4. На часах открываете приложение, выбираете документ из списка и листаете его.

PDF не перетекает по ширине экрана: строки уже разбиты под ту страницу, на которую он собран. Поэтому обычный документ формата A4 на часах читать невозможно, и документы нужно собирать специально под часы (см. раздел «Как подготовить PDF»).

---

## Что понадобится

| Что | Зачем |
|---|---|
| Mac с актуальным **Xcode** | сборка и установка приложения |
| **Apple Watch** с watchOS 10 или новее | запуск приложения |
| **iPhone**, к которому привязаны эти часы | Xcode подключается к часам через парный iPhone |
| Кабель iPhone -- Mac | подключение при первой установке |
| **Apple ID** (бесплатного достаточно) | подпись приложения |
| LaTeX (по желанию): MacTeX, TeX Live или Overleaf | подготовка PDF |

Приложение проверялось на Apple Watch SE (watchOS 10.6.2) с Xcode 27 и iPhone на iOS 27.

## Быстрый старт

### 1. Скачайте проект

```bash
git clone https://github.com/<ваш-аккаунт>/<название-репозитория>.git
cd <название-репозитория>
open LaTeXReader.xcodeproj
```

Либо нажмите на GitHub **Code → Download ZIP**, распакуйте и откройте файл `LaTeXReader.xcodeproj`.

### 2. Настройте подпись под себя

Проект привязан к аккаунту автора, поэтому два параметра нужно заменить на свои.

1. В навигаторе слева (**⌘1**) выберите корень проекта `LaTeXReader`.
2. В списке **TARGETS** выберите `LaTeXReader Watch App`.
3. Вкладка **Signing & Capabilities**:
   - **Team**: выберите свой Apple ID. Если его нет в списке, добавьте в **Xcode → Settings → Accounts**.
   - **Bundle Identifier**: измените на уникальный, например `com.ivanov.LaTeXReader`. Одинаковые идентификаторы у разных людей конфликтуют.
4. То же самое повторите для второго таргета `LaTeXReader` (если он есть в списке): выберите свой Team и идентификатор вида `com.ivanov.LaTeXReader` (без суффикса `.watchkitapp` у него, у таргета часов суффикс останется).

### 3. Проверьте версию watchOS

Минимальная версия, с которой приложение собирается, указывается в **General → Minimum Deployments → watchOS**. Она не должна быть выше версии на ваших часах.

Версию на часах можно посмотреть на iPhone: **Watch → Основные → Об этих часах → Версия**. Если на часах, например, watchOS 10.4, поставьте в Minimum Deployments значение **10.0**.

Значение нужно поменять **в трёх местах**:
- таргет `LaTeXReader Watch App`;
- таргет `LaTeXReader` (обёртка);
- сам проект: слева выберите **PROJECT → LaTeXReader**, вкладка **Info → Deployment Target**.

### 4. Добавьте свои PDF

1. В Finder подготовьте файлы (см. следующий раздел).
2. В Xcode перетащите их на группу `Documents` в навигаторе слева.
3. В диалоге включите **Copy items if needed**, выберите **Create groups** и поставьте галочку у таргета **LaTeXReader Watch App**.
4. Проверьте: таргет `LaTeXReader Watch App` → **Build Phases → Copy Bundle Resources**. Ваши PDF должны быть в списке.
5. Старые тестовые PDF автора можно удалить из проекта (правый клик → **Delete → Move to Trash**).

Название документа в списке на часах берётся из имени файла без расширения. Пробелы и кириллица допустимы: `Лекция 1.pdf`.

### 5. Установите приложение на часы

Подробно это описано ниже в разделе «Установка на часы». Если вы хотите сначала просто посмотреть, как это выглядит, выберите вверху Xcode симулятор часов (например, Apple Watch SE) и нажмите **Run (⌘R)**. Симулятор не требует ни iPhone, ни кабеля.

## Как подготовить PDF для часов

### Почему нельзя взять обычный PDF

Экран Apple Watch имеет ширину около 170--205 pt. Страница A4 шириной 595 pt при вписывании в экран уменьшается примерно втрое: шрифт 11 pt превращается в 3--4 pt, и читать невозможно. Нужна **узкая страница с крупным шрифтом**.

Размер шрифта на экране приблизительно равен:

```
размер на экране ≈ размер шрифта в документе × (ширина экрана ÷ ширина страницы)
```

Цель: **11--13 pt на экране**. Для ширины страницы 60 мм и шрифта 12 pt получается около 12 pt на экране, примерно 22--25 символов в строке.

### Шаблон преамбулы для XeLaTeX

```latex
\documentclass[12pt]{extarticle}
\usepackage{fontspec}
\usepackage{polyglossia}
\setmainlanguage{russian}
\IfFontExistsTF{Helvetica Neue}{\setmainfont{Helvetica Neue}}{\setmainfont{DejaVu Sans}}
\usepackage{amsmath, amssymb}
\usepackage{enumitem}
\usepackage[paperwidth=60mm, paperheight=140mm,
            left=2mm, right=2mm, top=6mm, bottom=2mm,
            includefoot=false, includehead=false]{geometry}

\pagestyle{empty}            % без номеров страниц и колонтитулов
\raggedright
\sloppy
\emergencystretch=3em
\setlength{\parindent}{0pt}
\setlength{\parskip}{0.5em}
\allowdisplaybreaks          % длинные формулы переносятся между строками
\setlist{nosep, leftmargin=*}

\begin{document}
Ваш текст.
\end{document}
```

Сборка: `xelatex file.tex` (дважды, если есть оглавление и ссылки).

- **Верхнее поле 6 мм** оставлено под системное время часов: оно может перекрывать верх страницы.
- Для pdfLaTeX замените `fontspec`, `polyglossia` и `\setmainfont` на `\usepackage[T2A]{fontenc}`, `\usepackage[utf8]{inputenc}`, `\usepackage[russian]{babel}`.
- Если нужна и обычная версия документа, и версия для часов, поставьте переключатель в начало преамбулы:

  ```latex
  \newif\ifwatch
  \ifdefined\WATCH \watchtrue \fi
  \ifwatch
    % параметры для часов (geometry с узкой страницей)
  \else
    \usepackage[a4paper, margin=2cm]{geometry}
  \fi
  ```

  Версия для часов собирается командой:

  ```bash
  xelatex -jobname=doc-watch "\def\WATCH{1}\input{doc.tex}"
  ```

### Что обычно ломается в узкой колонке

| Проблема | Что делать |
|---|---|
| Длинные формулы выходят за край | разбить через `align`/`aligned`/`split`, либо пакет `breqn` (`dmath`); переносить перед знаками `=`, `+`, `-` |
| Широкие таблицы | столбцы с переносом `p{15mm}`, `tabularx`, либо превратить таблицу в список |
| Картинки | `\includegraphics[width=\linewidth]{...}`, мелкие подписи на графиках проверять глазами |
| Большие отступы и номера страниц | `\pagestyle{empty}`, `\setlength{\parindent}{0pt}` |

### Если исходников нет, есть только готовый PDF

- Обрезать поля: `pdfcrop --margins 0 input.pdf cropped.pdf`.
- Перекомпоновать страницы в узкие инструментом `k2pdfopt`:
  `k2pdfopt -w 360 -h 900 -dpi 167 -ml 0.02 -mr 0.02 -x input.pdf`.
  Для обычного текста результат приемлемый, формулы и таблицы могут разорваться.

### Помощь нейросети

Адаптировать документ под часы можно и с помощью нейросети: опишите ей параметры страницы (60 мм ширина, шрифт 12 pt, поля 2 мм, верх 6 мм, без колонтитулов) и попросите не менять содержание, а только вёрстку, перенеся длинные формулы и таблицы.

## Установка на часы

Приложение ставится из Xcode. App Store и TestFlight для этого не нужны.

### Один раз: подготовка

1. **Включите режим разработчика на iPhone**: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Потребуется перезагрузка.
2. Подключите iPhone к Mac кабелем, разблокируйте и нажмите **Доверять**.
3. В Xcode откройте **Window → Devices and Simulators** (или Device Hub), выберите свой iPhone. Под ним должны появиться ваши часы. Включите **Connect via network**.
4. **Режим разработчика на часах**: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Пункт появляется только после того, как Xcode увидел часы через iPhone. Включите, подтвердите перезагрузку часов, а после неё подтвердите включение ещё раз на самих часах.
5. Убедитесь, что в Device Hub у часов **Developer Mode: Enabled** и **Tunnel State: Connected**.

### Запуск

1. Вверху Xcode в списке устройств выберите свои часы.
2. Нажмите **Run (⌘R)**.
3. При первом запуске macOS может попросить пароль для `codesign`: введите пароль от Mac и нажмите **Always Allow**.
4. При первой установке на новую версию watchOS Xcode копирует с часов системные библиотеки (**Copying OS library symbols**). Это может занять от 10 минут до получаса. Не прерывайте процесс, держите часы разблокированными, на руке или на зарядке.
5. Если на часах появится сообщение о ненадёжном разработчике: на iPhone **Настройки → Основные → VPN и управление устройством** и доверьте свой сертификат.

### Срок действия

С **бесплатным Apple ID** приложение работает **7 дней**, после чего его нужно переустановить из Xcode (часы для этого снова должны быть видны). С платным аккаунтом разработчика срок действия больше.

### Добавить или заменить документы позже

Приложение показывает только те PDF, которые были в проекте на момент сборки. Чтобы добавить новый документ, положите его в проект (шаг 4 «Быстрого старта») и снова нажмите **Run**.

## Как пользоваться на часах

- Список документов показывает все PDF, лежащие в приложении.
- Выберите документ, и он откроется на весь экран.
- Прокрутка пальцем. Digital Crown меняет масштаб страницы (если вы не меняли код).
- В начале и в конце документа есть кнопка **Назад**, которая возвращает к списку.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Список документов пустой | PDF не попали в таргет часов. Проверьте **Build Phases → Copy Bundle Resources** и Target Membership файлов, затем **Product → Clean Build Folder (⇧⌘K)** и Run |
| `doesn't match ... deployment target` | Версия watchOS на часах ниже Minimum Deployments. Понизьте значение в трёх местах (см. шаг 3) |
| Часов нет в Xcode / Device Hub | Часы и iPhone разблокированы, на iPhone включён режим разработчика, Mac, iPhone и часы в одной Wi-Fi сети, VPN выключен. Нажмите **Edit Visibility** в Device Hub. Перезагрузите часы и iPhone, перезапустите Xcode |
| Нет пункта «Режим разработчика» на часах | Он появляется после того, как Xcode увидел часы. Выключите и снова включите режим разработчика на iPhone (с перезагрузкой), перезагрузите часы, подключите iPhone кабелем и откройте Devices and Simulators |
| `Bluetooth connection ... invalidated before tunnel could be created`, `Control channel connection timed out` | Не установился канал связи. Дождитесь **Tunnel State: Connected**, поставьте часы на зарядку, не давайте им засыпать, проверьте Wi-Fi и повторите Run 2--3 раза |
| «Copying OS library symbols» долго висит на 0% | Это нормально для первого запуска, дождитесь окончания. Часы, iPhone и Mac не должны засыпать |
| Окно `codesign wants to access key` | Введите пароль от Mac, нажмите **Always Allow** |
| Страница на часах мелкая или с большими полями | Подберите `paperwidth` и размер шрифта в LaTeX; ширина 60 мм подходит для большинства моделей |
| Слишком крупный или мелкий текст на разных часах | Размеры экранов отличаются не более чем на 20--25 %. Ориентируйтесь на среднюю модель и проверьте на симуляторе самой маленькой и самой большой |

## Ограничения

- На часах нет TeX-движка, PDF нужно собирать заранее.
- Новые документы появляются только после пересборки и переустановки приложения.
- При использовании бесплатного Apple ID приложение нужно переустанавливать раз в 7 дней.
- Формулы и таблицы шире страницы нужно вручную переносить в LaTeX, иначе они обрежутся.
- Полноценный просмотр PDF средствами PDFKit на watchOS недоступен, поэтому страницы рисуются через CoreGraphics в изображения.

## Структура проекта

```
LaTeXReader/
├── LaTeXReader.xcodeproj
└── LaTeXReader Watch App/
    ├── LaTeXReaderApp.swift     # точка входа
    ├── ContentView.swift        # список документов и просмотр PDF
    ├── Assets.xcassets
    └── Documents/               # сюда кладутся ваши PDF
```

Основная логика живёт в `ContentView.swift`: поиск PDF в бандле (`findPDFs`), рендеринг страницы в изображение (`renderPage`), экран прокрутки (`PDFScrollView`).
